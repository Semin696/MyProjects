## 2. Питание

Реле SRD-05VDC-SL-C: катушка **5 V DC, 70–90 мА**. ESP8266 в момент отправки по WiFi
потребляет до 400–500 мА. Отдельного блока питания на реле не хватит — считаем вместе.

```
        Блок питания 5 В, 1–2 А
     ┌───────────────────────────────┐
     │  +5V            GND           │
     └───┬─────────────────────┬─────┘
         │                     │
         │   ┌─────────────────┴──────────────┐
         │   │   общий GND (обязательно!)     │
         │   │  ESP8266 GND  +  GND реле      │
         │   └─────────────────┬──────────────┘
         │                     │
   реле VIN (5V)          реле +5V (пин 1)
   реле GND              общий GND
```

* ESP8266MOD: `VIN` = 5 V (на платах NodeMCU/ESP-12E). Если плата питается от USB — в розетку
  блока питания реле **не включать**, только общий GND.
* Реле: 5 V берём **того же** блока питания, GND обязательно соединяем с GND ESP.
* Никогда не сажай 220 В на выводы ESP8266.

## 3. Управление реле (нужен транзистор!)

Обмотка реле потребляет ~80 мА — напрямую с пита ESP8266 (12 мА максимум на пин) она не
потянет, а транзистор обязателен и для защиты вывода.

```
                        +5V (блок питания)
                         │
        ┌────────────────┴────────────────┐
        │                                 │
   ┌────┴──────────────┐                  │
   │ 1N4148 (диод)     │                  │
   │ катод ← к +5V     │                  │
   └────┬──────────────┘                  │
        │ анод                            │
   ┌────┴──────────────┐                  │
   │ SRD-05VDC-SL-C    │                  │
   │ пин 1 = «+» обмотки│                 │
   │ пин 2 = «−» обмотки│                 │
   └────┬──────────────┘                  │
        │                                 │
        └──────────┐                      │
                   │ C                    │
 ESP8266MOD    ┌───▼───┐                  │
 GPIO5 (D1)    │ 2N2222│  NPN-транзистор  │
   │           │  Q  E │  (подойдут       │
  [1 kΩ]       └───┬───┘   2N3904, S8050) │
   │               │                     │
   └───────────────┤                     │
                B │                     │
                   └─────────────────────┴──── общий GND
```

* **D1 (NodeMCU) = GPIO5** — пин, управляющий транзистором. В коде: `RELAY_PIN = D1`.
* `1 kΩ` — резистор между GPIO5 и базой транзистора (защита вывода от тока базы).
* Диод 1N4148 ставится **параллельно обмотке**, катодом к `+5V`, анодом к коллектору
  (к выводу обмотки «−»). Он гасит выброс напряжения при отключении.
  Для больших обмоток можно 1N4007.
* Если вместо транзистора используешь готовый модуль реле на 5 V с LOW-триггером —
  оставь `ACTIVE_LOW = true` (значение по умолчанию), схема транзистора тогда не нужна.

### Таблица подключения

| ESP8266MOD | Куда | Примечание |
|---|---|---|
| `VIN` (5 V) | `+5V` блока питания | либо USB, но не оба сразу |
| `GND` | общий `GND` | обязательно |
| `D1` (GPIO5) | база через 1 kΩ | управление реле |
| — | `+5V` | пин 1 обмотки реле |
| — | `GND` | пин 2 обмотки реле (через коллектор транзистора) |
| — | 1N4148 | катод к +5V, анод к коллектору |

## 4. Контакты реле и нагрузка 220 В

Реле — SPDT (переключающий), три вывода: `COM`, `NO` (норм. разомкнутый), `NC` (норм. замкнутый).
Для лампы/прибора используем `COM` + `NO`: пока реле выключено — цепь разомкнута (состояние
«выключено по умолчанию», самое безопасное).

```
  ~220 В          щиток / автомат          реле               нагрузка
   L ────────[ автомат 6–10 А ]──────┬──── COM
                                     │
                              ┌──────┴──────┐
                              │   SRD-05    │
                              │  NO    NC   │
                              └──────┬──────┘
                                     │ NO
                                  [лампа / прибор]
                                     │
  N ────────────────────────────────┴────────────
```

* Щиток/автомат и раздельный предохранитель — обязательны.
* Паяйте и подключайте 220 В только при обесточенной сети, в сухом месте.
* Не управляй через эти контакты зарядными устройствами, нагревателями и прочим,
  где важна гальваноразвязка и точное отключение нуля.

### Как найти выводы реле, если непонятно с нумерацией

1. Мультиметр в режиме сопротивления: два вывода с сопротивлением ~70–90 Ом — это **обмотка** (5 V).
   Остальные три (70–150 Ом при замере в одном положении) — **контакты**, между ними
   прозвонка: `COM`–`NC` замкнут, `COM`–`NO` разомкнут (реле выключено).
2. Разрешение проводов реле: 5 V на обмотку — «+» на пин 1, «−» на пин 2.
3. Уточнить по даташиту: у SRD оба вывода обмотки иногда подписаны `VCC`,
   а контакты идут `COM / NC / NO`.

## 5. Прошивка и запуск

1. Установить плату ESP8266 Generic (в Arduino IDE) и библиотеки `ESP8266WiFi`,
   `ESP8266WebServer`, `ESP8266HTTPClient`, `DNSServer` (входят в пакет ESP8266).
2. Прошить `esp12f_server.ino` на ESP-12F.
3. Прошить `esp8266_relay.ino` на ESP8266MOD, при необходимости поменять вверху файла:
   * `DEVICE_NAME` — имя устройства (латиницей, без пробелов);
   * `RELAY_PIN` — свой пин (для D1 это `D1`, он же GPIO5);
   * `AP_SSID` / `AP_PASS` — те же, что на сервере.
4. Настройки сервера (вверху `esp12f_server.ino`): `AP_SSID` (имя сети, **минимум 8 символов
   вместе с паролем**), `AP_PASS` (пустая строка — сеть без пароля), `MAX_DEVICES`.

### Управление

* Телефон или ПК: WiFi → сеть `UmDom` → в браузере `http://192.168.4.1/` (или любой адрес —
  сервер перекинет на панель). Кнопка **ВКЛ/ВЫКЛ** у каждого устройства, список
  обновляется сам раз в 1.2 с. Устройство без связи подсвечивается полупрозрачным.
* Консоль сервера (Serial Monitor 115200): `list`, `on 0`, `off 0`, `toggle 0`, `info`, `help`.
* Консоль устройства: `status`, `on`, `off`, `toggle`, `name Relay-3`, `scan`, `reset`.

### Как связаны сервер и устройство

| Шаг | Что происходит |
|---|---|
| 1 | Устройство каждые 10 с сканирует эфир и ищет сеть `UmDom` |
| 2 | Найдя — подключается и получает `192.168.4.x` |
| 3 | Каждые 2 с: `GET /api/dev?id=<chipid>&name=<имя>&type=relay` — это и регистрация, и опрос |
| 4 | Сервер отвечает `1` или `0`; устройство включает/выключает реле |
| 5 | Если нет ответа 5 раз подряд (10 с) — устройство отключается и ищет сеть заново |
| 6 | Сайт шлёт `GET /api/toggle?id=<chipid>` — состояние меняется на сервере, реле подхватывает в следующем опросе |
| 7 | Нет связи с устройством > 7 с — в панели статус «нет связи» |

Особенности:

* Устройство может появиться в панели не сразу — как только наберёт адрес (обычно 2–10 с).
* Состояние реле хранится в памяти сервера и **не сохраняется при перезагрузке**: после
  ресета всё в положении ВЫКЛ (безопасно).
* Интернет через сервер не раздаётся: ESP8266 не умеет NAT/routing. Сеть `UmDom` — только
  для управления, у каждого устройства нет выхода в интернет.
* Пока сервер выключен, устройство непрерывно сканирует эфир и ждёт сеть — как только
  сервер включили, они подхватят её сами.

## 6. Проверка без 220 В

Пока не подключайте нагрузку: 1-я ножка реле (обмотка) питается от 5 В, а на выходах
`COM`/`NO` измерьте мультиметром в режиме continuity — при команде `on` должен появиться
звук/пропадание сопротивления между `COM` и `NO`.
